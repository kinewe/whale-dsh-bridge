>
> - 仓库根目录 `README.md`

>
> 为准。

## 当前最短流程

```text
1. 从上游安装鲸鱼娘并确认网页聊天能回
2. 运行 plugin/dsh-whale-bridge/install-dsh-plugin.ps1
3. 刷新 DSH，打开「鲸鱼娘桥接」
4. 配置工作区 / 权限 / brain=dsh
5. 打鲸鱼娘原生补丁
6. 面板「接入鲸鱼娘」→「一键启动全链路」
7. 先测网页聊天，再测微信
```

## 与旧记录的主要差异

- 当前参考部署是 `brain=dsh`，聊天回复也由 DSH 会话生成；
- 旧记录默认 `brain=upstream`，只把任务交给 DSH；
- 当前桥接支持自动拉起鲸鱼娘和微信桥接；
- 路径不再写死在文档里，按实际环境配置。

详细步骤见 [docs/install-with-dsh.md](../../../docs/install-with-dsh.md)。
